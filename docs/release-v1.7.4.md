## 本次更新

### 修复

- **已有按键无法修改**：「绑定输入」对话框用按钮上显示的文字判断当前是「移除」还是「替换」。汉化把 `Remove` 显示成「移除」后，游戏的英文比较永远不成立，两个按钮点了都没反应。现在游戏逻辑统一读取原始英文，界面仍显示中文，「替换」可以正常进入按键监听，「移除」也能清掉绑定。
- **贴纸 / 涂装分类点击后列表为空**：分类按钮的显示文字被直接拿去做 `Category` 匹配。汉化分类名后筛选不到任何贴图。现在分类筛选读取原始英文，显示层继续翻译；同时恢复 22 个分类名的中文翻译（`Animals → 动物`、`Camo → 迷彩`、`Vegetation → 植被` 等），`Jundroo` 品牌名保留英文。
- **可折叠分区状态键**：标题显示文字不再被当作展开状态的字典 key。
- 补齐按键绑定对话框、按键冲突提示、按键监听提示以及教程属性分区提示的拼接句翻译（`{*}` 模板），避免底层修复后这些提示退回英文。

### 词库与术语

10,469 条词条（8,757 条译文 + 1,712 条刻意保留英文）。本次新增 22 条贴纸 / 涂装分类名和 6 条拼接句模板，并做了以下精校：

- 修正航空术语：推力中心（CoT）、气动面积 / 阻力、发动机矢量偏转、导弹高抛弹道、反作用控制喷口、瞄准吊舱、垂直速度表、迎角、滚转、质心等
- 修正误译：航母升降机（不是飞机升降舵）、每秒最大导弹数、饰边 / 进气口饰边、碰撞体数量、激活器等
- 补回 130 条涂装样式的数字编号，避免界面重名
- 补翻常用单位；`Boom 25` / `Boom 50` / `Lazy 50` / `Cleaver` 是武器型号名，按代号保留英文，只翻译描述
- 保留快捷键提示中的 `<b>` 加粗标签
- 支持 `{0} Mech{1} Remaining` 这类英文复数模板，`3 Mechs Remaining` 会显示为「剩余 3 机甲」

### 说明

- 安装器与安装逻辑不变，版本号同步到 1.7.4。
- 按键与分类的修复位于插件 DLL，需安装完整包或覆盖插件 DLL；仅热更新词库不会修复这两处逻辑问题。

## 安装

下载 `SP2Chinese-Setup-v1.7.4.exe`，双击运行，点「开始安装」。Release 页面里的 Source code 是源码，不是安装包。

## 校验

安装包内 `manifest.json` 记录了每个文件的 SHA256，安装器会在写入前后各校验一次；游戏内词库更新也会校验哈希后才热重载。
