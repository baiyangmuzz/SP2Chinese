安装器界面

安装

  1. 从 Releases 下载 SP2Chinese-Setup-v1.7.0.exe（不要下 Source code，那是源码包）
  2. 双击运行，管理员授权选「是」
  3. 点「开始安装」，显示「安装完成」后就能进游戏

安装前请先退出游戏。安装器会自己找 Steam 游戏目录，找不到才让你选。

安装器会做什么

  • 写入前校验包体，写入后逐个核对 SHA256，任一步失败自动回滚到安装前的状态
  • 已有的 BepInEx 和其它模组不会被覆盖
  • 装完顺带把词库更新到最新；本地词库比包内新时保留本地
  • 没用懂可以点「回滚版本」，从历史备份里选一个恢复

常见问题

Windows 提示「已保护你的电脑」怎么办？
这个 exe 没有做代码签名，Windows 会对未签名的程序弹这个提示。 点「更多信息」→「仍要运行」即可。不放心的话，仓库里第一个版本的全部源码和打包脚本都在， 可以自己编译比对。
装完进游戏还是英文？
汉化通过 BepInEx 在运行时替换文本，游戏必须通过 Steam 启动（直接双击游戏 exe 通常也能生效， 但 Steam 启动最稳）。如果装了别的 BepInEx 插件，可能有冲突，先看 BepInEx\LogOutput.log。
怎么卸载？
再运行一次安装器，点「卸载汉化」。插件目录会被移到 BepInEx\_mod_backups，不删文件；BepInEx 本体和其它模组不受影响。
游戏更新后还能用吗？
多数情况可以直接用。游戏大更新导致部分文本对不上时，等新版词库或插件即可， 词库是支持游戏内热更新的，不用重装。
会影响联机吗？
汉化只替换界面文本，不改游戏逻辑。但联机时请遵守服务器规则；和其它模组一起用时， 出问题的概率会高一些。
