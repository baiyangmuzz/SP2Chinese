# Steam 指南 v2 · 分章节填写对照

> Steam 指南是「介绍 + 多章节」结构。第一步的介绍框填导语，
> 之后每点一次「添加章节」填一节。内容框直接粘贴 BBCode 文本，
> Steam 会自动渲染加粗和列表。

```
本指南介绍如何为 SimplePlanes 2 安装一套完整的简体中文补丁，覆盖主菜单、
设计器、教程、联机聊天在内的全部游戏文本。开源免费，由社区维护，
支持自动更新与版本回退。获取方式见末尾章节。
```

语言：简体中文。横幅：汉化后主菜单截图压成 800×195（避免用安装器截图）。

### 章节 5

标题：`词库更新`

内容：

```
不联网也可以正常使用。

如果你用 Watt Toolkit / Steam++ 加速 GitHub，开着加速再执行检查，命中率更高。
```

### 章节 6

标题：`常见问题`

内容：
```
[b]Q：进游戏还是英文？[/b]
1. 确认从 Steam 正常启动，不要用其他快捷方式
2. 完全退出游戏（含后台）重新打开
3. 打开 BepInEx\LogOutput.log，确认有 "SP2 chinese"

[b]Q：支持 macOS 吗？[/b]
暂不支持，当前方案仅限 Windows。
```

## 操作细节（对应你截图 2 的界面）

1. 每节填完点右下角「保存」，再点「添加章节」建下一节
2. 章节顺序可以拖动调整；链接放最后一节是刻意设计（正文弱化分发导向）
3. 右侧「图片/视频」面板：每节可配图，建议章节 1 配汉化后主菜单图、
   章节 3 配安装器进度条图——图文混排的指南通过率与观感都更好
4. 全部章节保存后回到指南主页检查渲染，确认没有「已移除」横幅
5. 如果再被移除：页面右上「联系我们」→「我认为此内容被错误移除」申诉；
   申诉期间不要重复发布
