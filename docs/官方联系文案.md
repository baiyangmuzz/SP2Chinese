## 三、使用建议

1. **先发 B 站私信，再发邮件**。B 站是官方的中文运营阵地，回应概率更高；
   邮件作为正式渠道并行推进。
2. **发邮件前打开一次仓库页面**，确认 README 渲染正常——对方点开链接的
   第一印象只有一次。
3. **不要催**。发出去之后该干嘛干嘛，真正的推动力是玩家数量：
   群里、B 站游戏区、simpleplanes.com 载具评论区，用的人多了官方自然会看到。
4. 两边都不要提另一个汉化项目（LQSC），不拉踩。
