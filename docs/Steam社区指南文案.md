## 指南正文（BBCode，整段粘贴）

```
[h1]SimplePlanes 2 汉化教程[/h1]

本指南介绍如何为 SimplePlanes 2 安装一套完整的简体中文补丁，覆盖主菜单、
设计器、教程、联机聊天在内的全部游戏文本。补丁开源免费，由社区维护。

[h2]汉化效果[/h2]
[list]
[*]10393 条词条：主菜单、设计器属性、零件悬浮说明、设置、全部教程
[*]87 架官方载具的介绍文字
[*]联机聊天、弹窗内的中文均正常显示，不会出现方块字
[*]官方载具名、挑战名、XML 属性与枚举值保留英文原文，方便照抄 XML
[/list]

[h2]准备工作[/h2]
[list]
[*]Windows 10 及以上系统（暂不支持 macOS）
[*]Steam 版 SimplePlanes 2
[*]不需要安装 BepInEx，不需要下载字体，补丁全部自带
[/list]

[h2]安装步骤[/h2]
[list]
[*]退出游戏
[*]从补丁的项目主页获取最新安装包（链接见本指南末尾）
[*]解压后双击 SP2汉化.bat，按菜单提示操作：选择 1 并回车即开始安装
[*]安装器会自动定位游戏目录，完成后逐文件校验
[*]启动游戏
[/list]

[h2]卸载与版本回退[/h2]
重新打开安装器即可：
[list]
[*]选择 2 卸载汉化，相关文件自动清理，不影响游戏本体与其他模组
[*]选择 3 可回退到之前的版本（安装器自动保留最近 3 次）
[/list]

[h2]词库更新[/h2]
补丁支持自动更新。安装器会尝试多个镜像源获取最新词库，下载后经校验再替换，
不联网也可以正常使用。如果你用 Watt Toolkit / Steam++ 加速 GitHub，
开着加速再执行检查，命中率更高。

[h2]常见问题[/h2]
[b]Q：进游戏还是英文？[/b]
1. 确认从 Steam 正常启动，不要用其他快捷方式
2. 完全退出游戏（含后台）重新打开
3. 打开 BepInEx\LogOutput.log，确认有 "SP2 chinese"

[b]Q：支持 macOS 吗？[/b]
暂不支持，当前方案仅限 Windows。

[h2]反馈与获取[/h2]
补丁的开源仓库与最新版本获取方式：
[url=https://github.com/baiyangmuzz/SP2Chinese]github.com/baiyangmuzz/SP2Chinese[/url]

发现哪里没翻译、哪里翻得不顺，欢迎到仓库提 Issue，或在 QQ 群 1128992783 反馈。
每次词库更新都会自动下发给所有用户，不需要重新安装。
```
