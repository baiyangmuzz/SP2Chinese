## 正文

```
玩简单飞机2的兄弟应该都遇到过，游戏是纯英文的，设计器里那些零件属性、
教程文字全看不懂，联机聊天更是没法看。

我自己做了一个完整的简体中文汉化，用了好几个月，现在稳定了发出来。

【能翻多少】

10469 条词条。主菜单、设计器里的零件属性、鼠标悬停说明、设置、教程、
飞行界面、联机聊天，基本能看到的中文都翻了。

87 架官方载具的介绍全文也翻了，选载具不用再开着翻译器看。

联机聊天和弹窗的中文不会变方块。中文字形是运行时生成的，这块专门处理过。

有一点要说明：载具名、挑战名、还有 XML 里的属性名和枚举值，我故意保留英文。
一是社区里大家用英文名字互相认载具，二是玩 XML 改造的时候要照着界面抄属性名，
翻成中文就没法抄了。

【怎么装】

下安装器，双击，点开始安装。完了。

安装器自己找 Steam 游戏目录，不用你手动翻路径。
装之前装之后都会校验文件，出问题会自动退回去。
卸载和回滚在同一个菜单里，出问题能退回上一个版本。
BepInEx 和字体都在安装包里，不用另外装。

【系统要求】

Windows 10 / 11
Steam 版 SimplePlanes 2
.NET Framework 4.8（系统自带）

【下载】

GitHub 搜 SP2Chinese，进 releases 页面下 SP2Chinese-Setup 开头那个 exe。
国内直连的话去 Gitee 搜 sp2-chinese，releases 里有同样的文件。

【Windows 拦截怎么办】

安装器没做代码签名，Windows 会弹「已保护你的电脑」。
点「更多信息」→「仍要运行」就行。源码在 GitHub 上，不放心可以自己编译。

【费用】

免费开源，不收费。有人收费那不是我。

发现哪里没翻、哪里翻得别扭，直接回帖说。词库支持游戏内更新，
改完推送下去，不用重装。
```

## 外链怎么处理（重要）

贴吧对外部链接审核很严，直接贴 GitHub/Gitee 完整网址容易：

- 被吞楼（帖子发出去但链接没了）
- 进审核队列，要等版主放行
- 严重的直接删帖

**稳妥做法**：正文里只写「GitHub 搜 SP2Chinese」「Gitee 搜 sp2-chinese」，不放完整网址。有人问再在回复里发，或者私信发。

如果一定要放链接，先用小号试发一条，看看会不会被吞，再决定正式帖怎么写。
