## 本次更新

### 安装器更新通道

- **安装器自更新优先走 Gitee**：检查更新时先读 Gitee 镜像的 `manifest.json`，下载安装包也优先用 Gitee 发行版附件；Gitee 不可达时才回落 GitHub / jsDelivr。
- 这样国内网络不需要先连 `api.github.com`，避免更新检查一开始就被卡住。
- 旧版 1.7.4 安装器仍然先查 GitHub，需要手动安装一次 1.7.5；从 1.7.5 起后续更新才会走新的 Gitee 优先通道。

### 词库与插件

- 翻译内容与 1.7.4 相同：10,469 条（8,757 条译文 + 1,712 条刻意保留英文）。
- 本次没有修改词库译文，只调整安装器更新通道和版本号。

### 安装

下载 `SP2Chinese-Setup-v1.7.5.exe`，双击运行，点「开始安装」。直接覆盖旧版即可，旧版会自动备份，不需要先卸载。

### 校验

安装包内 `manifest.json` 记录了每个文件的 SHA256，安装器会在写入前后各校验一次；安装器自更新下载完成后也会先校验 SHA256 再替换。
