```
# SP2Chinese

SimplePlanes 2 简体中文汉化补丁 · v0.7.10

自研 BepInEx 插件，非 XUnity 机翻方案。词库对照游戏原文逐条编写，
覆盖界面、设计器、教程与联机聊天。

## 特性

- **10,441 条词条**：主菜单 / 设计器属性 / 零件悬浮说明 / 设置 / 教程 / 飞行界面 / 联机聊天
- **87 架官方载具**：说明文字全文翻译
- **中文字形运行时生成**：聊天、弹窗均正常显示，无方块字
- **机器标识保留英文**：载具名、挑战名、XML 属性名与枚举值，照抄 XML 不会出错
- **安装器自带 BepInEx 与字体**：无需预先安装任何依赖
- **写入前后 SHA256 校验**：任一步失败自动恢复安装前状态
- **卸载与回滚**：同一菜单完成，保留最近 3 个版本
- **词库热更新**：14 个镜像源，游戏内更新，无需重装

## 快速开始

### 环境要求

- Windows 10 / 11（暂不支持 macOS）
- Steam 版 SimplePlanes 2
- .NET Framework 4.8（系统自带）

### 安装

1. 下载 `SP2Chinese-Setup-v1.7.3.exe`
2. 双击运行，UAC 授权选「是」
3. 点「开始安装」
4. 启动游戏

安装器自动定位 Steam 游戏库，无需手动填写路径。

### 卸载 / 回滚

重新运行安装器：

- 选「卸载汉化」：移走插件目录，BepInEx 本体与其他模组不受影响
- 选「回滚版本」：恢复至任一历史版本

## 下载

- GitHub Releases：https://github.com/baiyangmuzz/SP2Chinese/releases/latest
- Gitee 镜像（国内直连）：https://gitee.com/baiyangmuzz/sp2-chinese/releases

## 注意

安装器未做代码签名，Windows SmartScreen 会提示「已保护你的电脑」。

处理方式：点「更多信息」→「仍要运行」。

源码与构建脚本在 GitHub 仓库中，可自行编译比对。

## 已知限制

- 仅支持 Windows（BepInEx Mono x64）
- 游戏大版本更新后，需等待词库适配
- 与部分修改同类 UI 文本的模组可能冲突，查看 `BepInEx\LogOutput.log` 定位

## 反馈

- 回帖，或加 QQ 群 1128992783
- 未翻译 / 翻译不当的内容，反馈后随词库更新下发，无需重装

## 许可

开源免费。第三方转载或二次分发请注明出处。
```

## 为什么这版是「程序员风格」

| 特征 | 体现 |
|---|---|
| 一句话定位 | 标题下一行说明「自研 BepInEx 插件，非 XUnity 机翻」，技术选型直接交代 |
| 特性条目化 | 8 条，每条「加粗关键词 + 冒号 + 具体范围」，可扫读 |
| 环境要求写版本 | Windows 10/11、.NET 4.8，不写「主流系统」这种模糊词 |
| 安装用动作序列 | 1/2/3/4，每步一个动作，不掺解释 |
| 单独的「已知限制」 | 主动写不支持 macOS、模组冲突——工程文档的标准做法 |
| 反馈给具体出口 | 回帖 / 群号 / log 路径，不写「欢迎反馈」 |

## 和上一版（口语版）的区别

- 口语版：「自己写的 BepInEx 插件，没走 XUnity 机翻路线」→ 有态度，但信息密度低
- 这版：「自研 BepInEx 插件，非 XUnity 机翻方案」→ 同样的意思，术语准确，一行说清
