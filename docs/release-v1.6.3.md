## 本次更新

### 安装器（主要变化）

- **图形界面**：双击 `SP2汉化.bat` 现在打开窗口界面，不再是黑底数字菜单。只依赖 Windows 自带的 PowerShell 5.1 + .NET Framework，**不需要额外安装任何运行库**，安装包体积不变
- **高分屏文字发虚已修复**：进程此前未声明 DPI 感知，在 125%/150% 缩放下整个窗口被位图拉伸导致发糊
- **群号可复制**：界面新增「复制群号」按钮，信息行也改成可选中复制（此前是一整行不可选的文字）
- 保留命令行用法：`-Silent -Yes` 无人值守、`-NoGui` 回到旧版菜单、`-TestUpdate` 诊断更新源

### 修复

- **约 250 条动态文本此前永不命中**：游戏用 C# 格式模板生成文本（`俯仰角在 {2:F0} 到 {3:F0} 度之间`、`Area {0,9}: ... {1:00.0000}` 等），运行时占位符已被替换成数字，而词库里存的是带格式说明符的原样写法。旧匹配逻辑只认从 `{0}` 开始的连续编号，导致这些文本全部漏译。现已支持非零索引、格式/对齐说明符、固定文本中的字面数字与命名槽位
- **载具说明中的 TAB 未转义**：`Vertigo IV` 一条说明整条错乱
- **快捷方式名称拼写错误**：`[ToggleSearchPartsPartsPanel]` → `[ToggleSearchPartsPanel]`
- **材质后缀被误译**：` [Instance]` / ` [Shared Instance]` 改成恒等行，避免破坏游戏资源查找

### 安全与健壮性

- **SHA256 校验前移**：改为覆盖写入**之前**先按包内 `manifest.json` 校验 payload 完整，任一失败自动回滚并返回非零退出码；旧实现是先覆盖再校验、失败也照样装完
- **移除第三方代理源**：14 个源里的 9 个第三方加速站已删除，只保留 GitHub raw 与 jsDelivr 官方节点；不再使用 `-sk` 降级丢弃证书校验
- **manifest 多源一致才采纳**：单个源被劫持无法再决定期望哈希
- **卸载备份不再被清理**：此前 `_mod_backups` 只保留 3 份，连续安装会把卸载备份删掉
- 只读文件覆盖失败、安装中途失败无回滚等问题已修

## 安装

解压后双击 `SP2汉化.bat`，在窗口里点「检查更新并安装」。Windows 10 及以上，无需安装 BepInEx 与字体。

**下载的是 `SP2汉化_v1.6.3_<日期>.zip`。**页面里的 Source code 是源码，不是安装包。

## 校验

安装包内 `manifest.json` 记录了每个文件的 SHA256，安装器会在写入前后各校验一次；游戏内词库更新也会校验哈希后才热重载。
